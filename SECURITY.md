# Security reports

Please avoid posting exploit details, credentials, personal files or sensitive
logs in public Issues or pull requests.

If GitHub displays **Report a vulnerability** in this repository's Security
tab, use that private reporting form. If that option is unavailable, open an
Issue containing only a request for a private security contact, without the
vulnerability details; the maintainer will arrange a private channel.

Only describe versions and conditions you have actually verified. AppWink's
Accessibility and selected-file access are macOS permissions and remain in the
free application. Developer ID signing, Apple notarization and Sparkle update
signatures protect distribution; they are unrelated to commercial activation.

This is a personal project. Reports are handled as availability permits; no
response-time commitment is made.
