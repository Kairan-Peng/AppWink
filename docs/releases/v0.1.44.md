# AppWink v0.1.44

Release candidate — not yet published.

## Changes

- AppWink is free software under GPL-3.0-or-later. The application no longer
  requires a trial, license key, activation, purchase or online entitlement check.
- Removes the commercial runtime and App Store/StoreKit packaging route.
- Retains the existing hotkey/Settings windows and the 0.1.43 feature scope,
  including the macOS 27 Hidden Bar repair.
- Preserves saved shortcuts, file/folder bookmarks, opening modes, ordering,
  language, appearance and feature preferences. Old commercial caches are inert.
- Keeps Developer ID signing, Apple notarization and Sparkle updates with the
  existing update trust. First-time source builds use only public dependencies.
- Adds Chinese/English README, GPL and complete version-matched third-party
  notices, plus a maintainer-controlled release path.

## Installation and permissions

The final free installer will be provided through GitHub Releases. This
installer candidate has not been published; previous installers retain their
historical behavior. Do not replace an announced artifact with new bytes.

Accessibility is still required for privileged application/input features.
File/folder opens use macOS native APIs and selected-file bookmarks. macOS may
ask separately for protected-file access. An app upgrade may require checking
Accessibility and Login Items again.

## Known boundaries

- No new clipboard history, audio mixer or expanded system monitor is included.
- Finder owns default folder window/tab/Space behavior.
- Hidden Bar uses public status items and system overflow; notches, auto-hide
  and multiple displays remain layout-dependent.
- Automated tests and local smoke checks do not establish all keyboard/mouse,
  multi-Space, fullscreen, hardware or OS-version combinations.
- Startup after a fresh macOS login has not yet been verified for this candidate.

## Verification

Build, tests, signatures, notarization and isolated upgrade results are recorded
in the local readiness report before publication. The candidate uses build45,
greater than the prior installed build44. No public release/feed is changed by
candidate validation.
