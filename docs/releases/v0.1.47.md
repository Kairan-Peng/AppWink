# AppWink v0.1.47

## 更新

- 菜单栏图标与新的蓝色眨眼键帽 Logo 对齐：采用圆角外框、内嵌键帽、弧形眨眼和圆点眼睛，移除旧笑嘴。
- 保留原生单色模板和 18 点尺寸，适配菜单栏的明暗背景。
- 重新拍摄热键配置与虚拟键盘界面，更新中英文 README 展示图。
- 保留现有快捷键、书签、功能设置、权限和自动更新信任链。

## 安装

支持 macOS 14 或更新版本，兼容 Apple Silicon / Intel。
使用 App 内「检查更新」升级，或下载 universal DMG 后替换 Applications 中的旧版。

## English

- Aligns the menu-bar symbol with the new winking keycap logo, including the rounded tile, inset keycap, curved wink and dot. Removes the old smile.
- Keeps the native 18-point monochrome template for light and dark menu bars.
- Refreshes the hotkey configuration and virtual keyboard screenshots in both READMEs.
- Preserves existing shortcuts, bookmarks, settings, permissions and update trust.
