# AppWink v0.1.46

## 更新

- 修复 macOS 27 下 Hidden Bar 分隔项位置错乱，收起时将箭头一起隐藏的问题。
- 首次升级后 Hidden Bar 会重建自己的布局位置；可按住 Command，将需要隐藏的图标重新拖到分隔线左侧。
- 换用新的蓝色眨眼键帽应用图标，优化各尺寸的清晰度和透明边缘；中文 slogan 更新为「应用，眨眼即达」。
- 快捷键、文件书签、权限、登录项设置和现有 Sparkle 更新信任链保持兼容。

## 安装

下载本版本 universal DMG，将 AppWink 拖入 Applications，替换旧版后启动。
支持 macOS 14 或更新版本，以及 Apple Silicon / Intel。
安装包使用 Developer ID 签名和 Apple 公证；无需清空本机配置。

## 验证范围

- 新增五项 Hidden Bar 控制器回归测试，覆盖紧凑安装、排队收起、稳定布局标识和操作取消。
- macOS 27.0.1 刘海屏实测展开顺序、手动/30 秒自动收起、重启和关闭后重新启用，箭头均保持可见。
- 新图标尺寸、重复生成、资源与独立 UI 验证；完整构建、测试和 universal 安装包验证。
- 多显示器、完整自动隐藏菜单栏、实际登录启动和全部物理输入组合未重新完成完整矩阵。

## English

- Fixes the Hidden Bar arrow disappearing when an inverted separator layout is restored on macOS 27.
- Resets only Hidden Bar's placement once. Command-drag the icons to hide to the separator's left afterward.
- Introduces the blue winking keycap app icon, clean transparent edges and correct icon sizes.
- Preserves shortcuts, file bookmarks, permissions, login settings and existing Sparkle update trust.

Download the universal DMG for macOS 14 or later and replace AppWink in Applications.
